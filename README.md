# Expense Tracker

## About the Project

Event Tracker is a simple and user-friendly expense tracking web application designed to help users manage their daily spending. It allows users to record expenses, organize them into categories, and monitor their daily spending through a clean and modern dashboard.

## Features

- **Add Expenses:** Record expenses using a description, amount, category and date.
- **View Transactions:** Display recorded expenses in an organized list.
- **Daily Expense Summary:** Automatically calculate and display total expenses for the day.
- **Transaction Count:** Display the number of expenses recorded today.
- **Data Persistence:** Uses LocalStorage to save expenses even after refreshing the browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## JavaScript Concepts

This project demonstrates the following JavaScript concepts:

- Object-Oriented Programming (OOP) using classes.
- Destructuring to extract object properties.
- Array methods: `map()`, `filter()` and `reduce()`.
- Spread operator to update arrays.
- Rest operator to handle multiple expenses.
